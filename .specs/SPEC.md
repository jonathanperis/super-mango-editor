## §I INTERFACES
id|surface|contract
I1|level/editor inputs|Validate numeric conversions and geometry before unsafe arithmetic or indexing; previews must tolerate invalid draft values without hiding editable data.
I2|rail helpers|One bounded rail placement/path implementation supplies runtime and editor positions; invalid geometry is rejected and offset normalization cannot loop indefinitely.
I3|gameplay|Immunity blocks damage, not pickups; death/reset terminates stale collision work; fresh levels reset transient state; nearest crossed surface wins; score arithmetic remains defined.
I4|input/persistence|Text entry takes priority over ordinary editor shortcuts; menu events use SDL logical coordinates; stale recovery metadata does not poison discovery; save/load identities are never silently truncated.
I5|verification|Replay/smoke simulation uses fixed steps, parses scripts once, fails on invalid scripts, and verifies observable results; editor smoke renders bounded frames; sanitizer coverage includes vendored parser.
I6|build/web|Absolute OUTDIR works; playtest resolves the sibling game executable; deployment uses the artifact source revision; standalone debug files are packaged together; web host keyboard suppression is focus-scoped and failures offer a reachable retry.
I7|profile|Versioned local profile stores settings, last played stage, and per-level best score/time/coins. Native uses atomic UTF-8 replacement with an OS-held per-profile lock and baseline comparison. Browser storage follows the locking/migration/acknowledgement contracts in I10/I11. Malformed/unreadable profiles remain untouched with a visible warning. Smoke/replay and tests do not touch personal profiles; --no-save disables persistence and --profile supports an explicit native path.
I8|settings UI|F1 opens options; menu Y/gameplay Back also open options. Navigation and Escape remain reserved/reachable. Keyboard and gamepad action bindings validate ranges/duplicates. Settings pause gameplay, apply on close, and persist through the session owner. Replay input stays independent of user bindings.
I9|metadata|Names/attribution retain existing bounds; descriptions support 4095 UTF-8 bytes. Oversized metadata fails transactionally instead of silently truncating; editor undo and hashing cover the complete stored value.
I10|browser persistence|New builds write a v2 storage namespace under a named exclusive Web Lock. Reads can use legacy v1 data only while v2 is absent; legacy bytes are never deleted or overwritten. Baseline comparison and replacement share the lock. Saves are asynchronous with bounded waits, explicit pending/success/failure states, and no C pointer captured by asynchronous JS. No unsafe unlocked-write fallback on unsupported browsers.
I11|save lifecycle|Profile baseline advances only after confirmed commit. Edits during a pending save remain dirty. Normal exit/replay waits for pending saves to settle; forced teardown cancels pending work. Save failures remain visible and never masquerade as success. Native synchronous profile behavior remains unchanged.
I12|touch input|Shared multi-pointer controls provide movement, jump/confirm, run, pause/back, and settings on both web hosts. Action masks are independent of user key bindings; matching SDL events support menus. Release/cancel/lost capture, blur/visibility loss, startup failure, shutdown, and scene changes clear holds. Controls are disabled before startup and after exit; keyboard shortcuts and page scrolling outside the game remain usable.
