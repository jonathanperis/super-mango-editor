# Archive

[SPEC.md](SPEC.md) is historical. It is the working specification of the
audit rounds of September 2026, written while the game still used SDL2: it
calls the project a C11/SDL2 one and names SDL throughout, and the game has
since been ported to raylib. It is kept so that the reasoning behind those
changes can be traced, and nobody updates it. For the project as it is now,
read [../project/STATE.md](../project/STATE.md),
[../project/ROADMAP.md](../project/ROADMAP.md) and the manual in `docs/wiki/`.
