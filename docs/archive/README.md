# Archive

These two files are historical. Each is a dated report on the repository as
it was on the day in its first lines: [AUDIT.md](AUDIT.md) is the
documentation and website audit of 2026-09-17, and
[AUDIT_IMPLEMENTATION.md](AUDIT_IMPLEMENTATION.md) is the Sandbox School
delivery report of 2026-09-16. They are kept so that the reasons behind later
changes can be traced, and nobody updates them. Do not read them for how the
project works today: the [manual](../wiki/) and the code are current, and
when a report disagrees with them, the report is the one that is out of date.
